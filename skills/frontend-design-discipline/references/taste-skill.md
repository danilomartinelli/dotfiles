# Taste skill reference

## Provenance

This reference is a concise adaptation informed by Leonxlnx's `taste-skill`
at commit `dfb6f9f9e93a39f673b1827c0889cc28326d1800`. The upstream work is
MIT-licensed; retain the upstream attribution when redistributing or adapting
this reference. This file is not a wholesale copy and does not install the
upstream skill.

## Adapted concepts

Use this reference as a prompt for intentional design decisions: identify the
purpose and audience, choose a coherent visual direction, make hierarchy and
interaction states explicit, and avoid default-looking output. Explain the
trade-offs behind notable choices instead of treating taste as an objective
or universal standard.

Apply these concepts only when all three conditions hold: (1) an identifiable
frontend or UI target/surface; (2) visual or interactive work; and (3)
creation of a new surface or a substantial redesign of an existing surface.
Accessibility, product requirements, existing project
conventions, and higher-authority instructions take precedence.

## Deliberately excluded

This adaptation excludes upstream prose copied at length, mandatory aesthetic
judgments, and any universal visual policy. It also excludes fixed framework
or library choices, CSS or component recipes, typography and color mandates,
asset or tooling requirements, and claims that a particular stack is present.

The owning `SKILL.md` is maintained separately. This reference does not
change runtime behavior, permissions, project configuration, or the scope of
any task.
