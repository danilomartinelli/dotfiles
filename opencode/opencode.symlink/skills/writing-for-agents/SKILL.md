# Writing for agents

Lead with the goal and constraints. Use short headings, imperative steps,
explicit inputs and outputs, and concrete paths or commands. Separate required
actions from optional context. Name the owner, permission boundary, evidence
needed, and rollback for consequential work.

Prefer one unambiguous instruction over several implied ones. Define project
terms locally, preserve Portuguese/English conventions already in use, and
avoid promising tools or permissions that are not available. End with the
appropriate verification and a concise report of paths and results.
